## 0.0.1

* Initial release with basic printing functionality

This version includes:

- A basic plugin manifest with no authentication required
- A simple OpenAPI specification exposing a single /ping endpoint
- A lightweight backend service to verify availability and connectivity
- Integration with the default platform channel, where the plugin is registered and enabled

The purpose of this release is to:

- Establish the core plugin structure
- Validate end-to-end connectivity between platform and service
- Serve as a foundation for future feature development

This version is intentionally minimal, focusing only on health checks and initial setup, with no advanced functionality or security layers yet implemented.
